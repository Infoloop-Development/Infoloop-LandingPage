# Image alt text in the CMS

**Audience:** Editors  
**Where:** Every image upload + **Settings → Media**

## How it works

1. **Every Media file requires Alt text.** When you upload or open an image in Media, fill **Alt text** (plain language: what the image shows).
2. That alt is used when the image fails to load, by screen readers, and for social previews (`og:image:alt`).
3. On galleries and product screenshots you can set an optional **Alt text override** for that placement only. Leave it blank to use the Media file’s alt.

## Tips

- Prefer describing the content (“OpsDeck attendance dashboard on a factory floor”), not “image” or “screenshot”.
- OG / social images: set alt on the Media file after you upload the 1200×630 graphic.
- Hero photos on Home: Media alt is preferred; the left/right alt fields are fallbacks for the placeholder slots.
